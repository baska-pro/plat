# Tata krama

Proyek ini kecil dan terbuka untuk siapa saja. Beberapa aturan sederhana:

- Bersikap sopan. Kritik data atau kode, bukan orangnya.
- Berikan sumber saat mengklaim sesuatu salah. Debat tanpa sumber tidak membantu siapa pun.
- Tidak ada pelecehan, ujaran kebencian, atau membagikan data pribadi orang lain, termasuk nomor plat lengkap milik orang lain beserta identitas pemiliknya.
- Maintainer boleh menyunting, menutup, atau menghapus komentar, issue, dan PR yang melanggar aturan ini.

Untuk melaporkan perilaku yang melanggar, hubungi maintainer lewat akun GitHub [baska-pro](https://github.com/baska-pro).
